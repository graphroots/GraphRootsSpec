# Security Policy

GraphRoots is a specification rather than running software, so "security" here
covers two things: (1) weaknesses you may discover in the design described by the
specification, and (2) any security-sensitive concern about this repository or
its contents.

## Reporting a concern

Please **do not** open a public issue for a security-sensitive report.

Instead, use GitHub's private vulnerability reporting for this repository:

1. Open the **Security** tab of this repository.
2. Choose **Report a vulnerability** to open a private security advisory.

We will acknowledge your report, investigate, and coordinate any needed changes
to the specification. Please give us a reasonable opportunity to address the
issue before public disclosure.

## Scope

- Design weaknesses in the specification itself.
- Issues affecting this repository.

For a vulnerability in a specific *implementation* of GraphRoots, please report
it to that implementation's own repository instead.
