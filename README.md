# GraphRoots Specification

GraphRoots is an open, publicly developed specification. This repository holds
the specification text and its development history. Implementations and
reference tooling live in separate repositories in the
[graphroots](https://github.com/graphroots) organization, each under its own
license.

> **Status:** Draft / work in progress. The specification has not yet reached a
> final, published version.

## Licensing at a glance

GraphRoots uses the [Open Web Foundation (OWF)](https://www.openwebfoundation.org)
agreements, which are designed specifically for openly developed specifications.

- **The specification** (this repository) is published under the **Open Web
  Foundation Agreement 1.0 (OWFa 1.0) — Copyright and Patent**. See
  [`LICENSE.md`](LICENSE.md). When the specification is finalized, supporting
  parties sign the OWFa to formalize their copyright licenses and patent
  commitments over the whole specification.
- **Contributions** are made under the **OWF Contributor License Agreement 1.0
  (OWF CLA 1.0) — Copyright and Patent**. Every contributor signs the CLA once,
  before their first contribution is merged. See [`CONTRIBUTING.md`](CONTRIBUTING.md)
  and the [`cla/`](cla/) folder.

Because OWFa is a specification license (not a standard software license),
GitHub's license picker will not auto-detect it; the authoritative text lives in
[`LICENSE.md`](LICENSE.md).
